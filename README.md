বাজার দর (BazarDor)

BazarDor is a marketplace web application designed to make online shopping simple and convenient.

Technologies:

- Next.js
- React
- Tailwind CSS
- HeroUI
- Better Auth
- MongoDB Atlas
- Google OAuth
- GitHub OAuth

Key Features:

1. Authentication
2. Product Browsing
3. User Profiles
4. Responsive Design
5. Simple navigation, notifications, and custom 404 page.
